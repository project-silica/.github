# .github

Organization-wide files for Project Silica: the organization profile
(`profile/README.md`), contribution guide, code of conduct, issue and pull
request templates, and the reusable CI workflows (`.github/workflows/`) that
every other repository calls with a few-line workflow file.

Belongs here: organization metadata and reusable workflows. Does not belong
here: code, or workflow logic that is not shared. Workflows call the same
`tools/` scripts used locally, so local and hosted results match.
